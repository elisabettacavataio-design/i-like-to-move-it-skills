# I Like to Move It · skills

Le skill del talk **AI Like to Move It, Move It** di Elisabetta Cavataio (Claude Community Event · Torino).

| Skill | Cosa fa |
|---|---|
| [`i-like-to-move-it`](./i-like-to-move-it) | The Motion Dictionary: un playground HTML per esplorare le animazioni di base, piegarne i parametri e copiare il CSS o il prompt per Claude. Demo: [`motion-dictionary.html`](./i-like-to-move-it/motion-dictionary.html). |
| [`move-it-workflow`](./move-it-workflow) | Il workflow (quasi) perfetto per creare reel e motion graphics con Claude, una tappa alla volta. |
| [`move-it-deck`](./move-it-deck) | Presentazioni animate in HTML come quella del talk: canvas 1920×1080, step a click, video locali, offline. |

## Come si usano
Ogni cartella contiene un `SKILL.md`. Scarica la cartella della skill che ti interessa (o tutto il repository) e aggiungila alle tue skill di Claude. Le istruzioni aggiornate per installare le skill sono nella documentazione di Claude: https://docs.claude.com

## Nota
Ricavate dagli esperimenti, non una metodologia universale. Usale, adattale, rendile tue.
